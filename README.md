# รพ.สต.บ้านคำยาง — ระบบเฝ้าระวัง สอบสวน และควบคุมโรค
Version 1.0.0 By Thanet

โครงสร้างระบบ
- **หน้าเว็บ (PWA)** = โฟลเดอร์นี้ → โฮสต์ที่ GitHub Pages
- **API + ฐานข้อมูล** = `Code.gs` บน Google Apps Script → เก็บข้อมูลใน Google Sheets

## ขั้นที่ 1 ตั้งค่า Apps Script (API)
1. เปิดโปรเจกต์ Apps Script เดิม **ลบไฟล์ `Index.html` ออก** แล้ววางโค้ด `Code.gs` ใหม่ทับของเดิม
   (ค่า Script properties เดิม เช่น `ADMIN_PASSWORD` และข้อมูลในชีตยังอยู่ครบ)
2. กด **Deploy > Manage deployments > ไอคอนดินสอ > Version: New version**
   (ถ้าเป็นโปรเจกต์ใหม่ ให้ **New deployment > Web app**) แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone** (ต้องเป็น Anyone เพราะหน้าเว็บเรียกจาก GitHub Pages)
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`
4. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ควรเห็นข้อความ JSON ว่า `"API พร้อมใช้งาน"`
5. ถ้ายังไม่เคยตั้ง ให้ไปที่ Project Settings > Script properties เพิ่ม `ADMIN_USERNAME` (เช่น `admin`) และ `ADMIN_PASSWORD`

## ขั้นที่ 2 ใส่ URL ในหน้าเว็บ
เปิดไฟล์ `config.js` แล้วแทนที่ `PASTE_APPS_SCRIPT_WEB_APP_URL_HERE` ด้วย URL `/exec` จากข้อ 1.3

## ขั้นที่ 3 โฮสต์ที่ GitHub Pages
1. สร้างบัญชี/ล็อกอิน GitHub แล้วสร้าง Repository ใหม่ (เช่น `bankhamyang-epi`) แบบ **Public**
   (GitHub Pages แบบฟรีใช้กับ repo แบบ Public เท่านั้น — ตัวหน้าเว็บไม่มีข้อมูลผู้ป่วย ข้อมูลอยู่ใน Google Sheets และต้องล็อกอินก่อนเข้าถึง)
2. กด **Add file > Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป โดยต้องคงโฟลเดอร์ `icons/` ไว้
   (`index.html`, `config.js`, `manifest.webmanifest`, `sw.js`, `icons/*.png`) แล้วกด Commit
3. ไปที่ **Settings > Pages** เลือก Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/` นี่คือลิงก์ที่แจกให้เจ้าหน้าที่

## ขั้นที่ 4 ใช้งานและติดตั้งบนเครื่อง
- เปิดลิงก์ ล็อกอินด้วย `ADMIN_USERNAME` / `ADMIN_PASSWORD` แล้วเพิ่มเจ้าหน้าที่ที่เมนู **ผู้ใช้งานระบบ**
- **iPhone/iPad (Safari):** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **Android (Chrome):** เมนู ⋮ → ติดตั้งแอป (หรือกดปุ่ม 📲 ติดตั้ง ในระบบ)
- **คอมพิวเตอร์/แล็ปท็อป (Chrome, Edge):** ไอคอนติดตั้งท้ายช่องที่อยู่เว็บ หรือปุ่ม 📲 ติดตั้ง

## เมื่อแก้ไขหน้าเว็บภายหลัง
แก้ไฟล์แล้วอัปโหลดทับใน GitHub และเปลี่ยนเลขเวอร์ชัน `CACHE` ในไฟล์ `sw.js` (เช่น `bankhamyang-v2`) เพื่อให้เครื่องที่ติดตั้งไว้ได้หน้าใหม่

## ล็อกอินด้วย Provider ID / ThaiD (ไม่บังคับ)
ต้องตั้ง Script property `REDIRECT_URI` เป็นลิงก์ GitHub Pages (ตัวอย่าง `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`) และลงทะเบียน Redirect URI เดียวกันนี้กับผู้ให้บริการ ต้องตรงทุกตัวอักษร
ปุ่มจะแสดงเฉพาะเมื่อตั้งค่ารหัสของผู้ให้บริการครบแล้ว (ดูรายการ Script properties ที่ส่วนหัวของหัวข้อ "การเข้าสู่ระบบ" ใน `Code.gs`)

## ข้อควรรู้
- ต้องมีอินเทอร์เน็ตจึงจะดู/บันทึกข้อมูลได้ (ออฟไลน์เปิดได้เฉพาะหน้าแอป)
- ข้อมูลอัปเดตอัตโนมัติด้วยการตรวจทุก 15 วินาที (Apps Script ไม่รองรับ WebSocket) ถ้าเจอปัญหาโควตา ให้เพิ่มรอบใน `startPolling` ใน `index.html` จาก `15000` เป็น `30000`
- URL ของ API เป็นสาธารณะ ใครที่รู้ลิงก์ก็เรียกได้ แต่ทุกคำสั่งที่เข้าถึงข้อมูลต้องมี token จากการล็อกอิน และระบบล็อกชื่อผู้ใช้ 10 นาทีเมื่อรหัสผิด 5 ครั้ง ควรตั้งรหัสผ่านให้ยาวและเดายาก
- ข้อมูลผู้ป่วยในระบบเป็นข้อมูลส่วนบุคคลด้านสุขภาพ ควรจำกัดสิทธิ์การเข้าถึง Google Sheets ของระบบไว้เฉพาะผู้ดูแล
